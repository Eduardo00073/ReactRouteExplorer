# Guia de Contribuicao

Obrigado por se interessar pelo react-route-explorer, um aplicativo de rotas em mapas com React e TypeScript integrado a API do Google Maps.

## Como contribuir

1. Faca um fork do repositorio.
2. Crie uma branch descritiva para sua alteracao.
3. Envie um Pull Request explicando o que foi mudado e por que.

## Sugestoes de contribuicao

- Melhorias de performance na renderizacao do mapa.
- Novos filtros ou funcionalidades de busca de rotas.
- Correcao de bugs de tipagem em TypeScript.

Toda contribuicao construtiva e bem-vinda!
